# A/B Testing Results Analysis

## Overview
This project analyzes A/B test results to evaluate whether a company should launch a new webpage or retain the existing version.

## Objectives
- Clean and explore the experimental dataset.
- Perform statistical hypothesis testing.
- Analyze conversion rates between the control and treatment groups.
- Draw conclusions and recommend an evidence-based decision.

## Tools Used
- Python
- pandas
- NumPy
- Matplotlib
- Statistical Analysis
- A/B Testing
- Regression Analysis
